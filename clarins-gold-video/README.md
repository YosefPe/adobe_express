# Club Clarins: Silver to Gold personalized video

A 26-second vertical (1080x1920) HyperFrames video for Club Clarins Silver members. It shows each member how far they are from Gold.

## Variables (one row per member)

| Variable | Type | Notes |
| --- | --- | --- |
| `firstName` | string | Greeting and CTA. Names over 9 characters get a smaller font. |
| `currentPoints` | number | Clamped to the Silver range (2,500 to 7,999). |
| `asOfDate` | string | Shown in the disclaimer. |
| `shopUrl` | string | Shown under the CTA button. |
| `memberId` | string | Unique id; used for the output file name. |
| `voiceover` | string | Path to the member's voiceover WAV (generated, see below). |

The video works out the rest:
- Points to Gold = 8,000 minus current points
- Estimated spend = ceil(gap / 11), using the Silver earn rate of 11 points per $1

## Scenes

1. Greeting: "Bonjour, {firstName}"
2. Current tier: Silver badge
3. Progress: points count up on a Silver-to-Gold bar, then the points still needed
4. Spend: dollar estimate and the 11 points per $1 earn rate
5. Gold perks: 12 points per $1, priority customer care, plus all Silver perks
6. CTA: "Shop now" and a disclaimer

## Audio

- **Voiceover (per member):** generated by `scripts/build-voiceover.mjs` with the Kokoro model, run locally through `hyperframes tts` (voice `af_heart`).
  - Each of the six lines is placed at its scene's start time.
  - A line that overruns its scene is re-generated up to 1.25x speed; if it still doesn't fit, the script stops with an error.
  - Numbers are spelled out so they are read correctly. The track is normalized to -16 LUFS.
- **Music bed:** `assets/audio/music-bed.wav`, synthesized by `scripts/make-music-bed.py`. It is a placeholder; replace it with a licensed Clarins track at the same path.
- **Sound effects:** soft whooshes on scene changes, a chime on the points gap, a sparkle on the Gold reveal and a click on the CTA. From the HyperFrames `media-use` bundled library.

Voiceover script:

1. "Bonjour, {firstName}."
2. "As a Club Clarins Silver member, you're one step from Gold."
3. "You have {points} points. Just {gap} more to Gold."
4. "That's about {dollars} dollars in your Clarins favorites."
5. "Gold earns twelve points per dollar, with priority customer care."
6. "{firstName}, Gold is within reach."

## Render

```bash
# one-time: Python with Kokoro
python3 -m venv .venv && .venv/bin/pip install kokoro-onnx soundfile numpy
export HYPERFRAMES_PYTHON=$PWD/.venv/bin/python

# optional: regenerate the placeholder music bed
.venv/bin/python scripts/make-music-bed.py assets/audio/music-bed.wav

# per member list: voiceovers + render-ready rows, then batch render
node scripts/build-voiceover.mjs members.sample.json members.render.json
npx hyperframes check
npx hyperframes render --batch members.render.json --output "renders/clarins-gold-{memberId}.mp4" --strict-variables
```

## Assumptions to verify with Clarins

- Tier thresholds (Member 0-2,499 / Silver 2,500-7,999 / Gold 8,000+) and earn rates (10/11/12 points per $1) come from third-party summaries of the Club Clarins US program. The clarinsusa.com pages could not be reached from the build environment.
- Brand red `#B40024` comes from a third-party brand-color listing.
- The wordmark is set in Cormorant Garamond as a stand-in. Replace it with the official Clarins logo SVG, and replace Cormorant Garamond and Jost with the brand's licensed fonts.
- The voiceover is synthetic (Kokoro `af_heart`, US English). Listen to "Bonjour" and "Clarins" before sending; if either sounds off, swap the voice or use a HeyGen or recorded voice.
- The music bed is synthesized and meant only as a placeholder.
